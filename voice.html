Call the front desk.

An AI receptionist that books and cancels appointments by voice. It reads your phone number back before it books, and it hands emergencies to a person straight away.

  • Bookings are real rows in Postgres, locked so two callers can never get the same slot.
  • Every change is tested against 18 kinds of simulated callers before it ships.
  • Speech in with Whisper, speech out with text-to-speech, same agent as the text chat.

Press the button and try I need an appointment tomorrow afternoon, then give a name and a 10-digit mobile number.

The bug only voice could find.

Whisper writes spoken numbers in groups, like 8127-8125-97. That is a valid ten-digit number, but the language model counted the digits wrong and told the caller it was invalid, over and over.

Counting is a job for code, not for a model. The fix merges digit groups before the agent sees them, and leaves validation to the booking tool. After the fix, 28 of 30 simulated calls booked with the right number and none booked a wrong one.

What happens when you speak.

The voice path is a thin layer over the same agent the text chat uses, so every test of the agent also covers voice.

  1. RecordYour browser records until you press the button again.
  2. TranscribeWhisper turns the audio into text, and digit groups are merged.
  3. DecideThe agent checks free slots and asks before it books.
  4. BookA locked Postgres transaction saves the booking once.
  5. ReplyThe answer is spoken back and shown above.
